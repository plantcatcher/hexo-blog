全国前三！广州地铁稳居第一梯队的核心底气

发表于2026-04-09|更新于2026-04-09|地铁
|浏览量:

同样是大城市地铁，为何广州能长期稳住全国前三的位置？超高客运效率、成熟运营经验、贴合城市发展的线路布局，让它在激烈竞争中始终保持优势。一文看懂广州地铁的真正实力。

广州地铁（Guangzhou Metro），是服务于中国广东省广州市等地区的城市轨道交通系统，为国际地铁联盟（CoMET）的成员，其首条线路广州地铁1号线于1997年6月28日开通运营，使广州成为中国内地第四座、华南地区首座开通地铁的城市。

截至2025年6月29日，广州地铁运营线路共19条，共设车站309座，换乘站61座，运营里程751.1千米，位列中国第三名。

截至2025年6月29日，广州地铁在建线路共有9条（段），其中广州地铁13号线二期首通段、广州地铁14号线二期首通段、广州地铁22号线后通段预计于2025年开通运营。

地铁

广州地铁1号线（Guangzhou Metro Line 1），是中国广东省广州市第一条建成运营的地铁线路，也是中国国内第一条由地方政府自筹资金兴建的地铁线路，于1997年6月28日一期工程观光试运营（西朗站[现西塱站]至黄沙站），于1999年2月16日开通二期工程运营（黄沙站至广州东站），于1999年6月28日正式运营（西朗站[现西塱站]至广州东站），其标志色为黄色。

广州地铁1号线，线路起于西塱站，途经天河区、越秀区和荔湾区，贯穿中山路，止于广州东站，大致呈西南至东北走向。

广州地铁1号线线路全长18.497千米，其中地面段2.048千米，地下段16.449千米。共设置16座车站，除西塱站、坑口站外，其余为地下站；列车采用6节编组A型列车。

广州地铁2号线（Guangzhou Metro Line 2），是中国广东省广州市第2条建成运营的地铁线路，于2002年12月29日开通试运营；于2003年6月28日正式开通运营首通段（三元里站至琶洲站）；于2005年12月26日开通运营二期工程（三元里站至万胜围站）；于2010年9月25日拆分为新广州地铁2号线（嘉禾望岗站至广州南站）。

广州地铁2号线南起于广州南站，途经番禺区、海珠区、越秀区和白云区，贯穿广州南站、广州火车站、白云新区，北止于嘉禾望岗站，大致呈“S型”南北走向。

广州地铁2号线全长31.8千米，全部为地下线；共设置24座车站，全部为地下车站；列车采用6节编组A型列车，最高时速80千米每时。

广州地铁3号线（Guangzhou Metro Line 3），是广州地铁第三条建成运营的线路，途经天河区、海珠区和番禺区，标志色为橙色。

2005年12月26日，广州地铁3号线开通运营首通段（广州东站至客村站）；2006年12月30日，开通运营一期工程（客村站至番禺广场站、天河客运站至体育西路站）；2010年10月30日，开通运营北延段（机场南站至广州东站）。2024年4月29日，广州地铁3号线东延段全线轨行区实现“三权移交”；10月30日，广州地铁3号线东延段完成项目建设与验收工作，通过初期运营前安全评估；11月1日，广州地铁3号线东延段（番禺广场站至海傍站）开通运营。

广州地铁3号线主线起于天河客运站，贯穿新中轴线区域、番禺区新城区等区域，止于海傍站；北延段起于体育西路站，途经天河区，白云区和花都区，止于机场北站，线路大致呈南北“Y字形”走向。广州地铁3号线线路全长74.01千米，全部为地下线；共设置34座车站，全部为地下站；列车采用6节编组B型列车。

广州地铁4号线（Guangzhou Metro Line 4）是中国广东省广州市第4条地铁线路，于2005年12月26日开通运营首通段（万胜围站至新造站）；于2006年12月30日开通运营广州地铁4号线二期首通段（新造站至黄阁站）；于2007年6月28日开通二期全线（万胜围站至金洲站）；于2010年9月25日开通运营北延段（车陂南站至黄村站）；2017年12月28日开通运营南延段（金洲站至南沙客运港站），其标志色为绿色。

广州地铁4号线起于黄村站，途经天河区、海珠区、番禺区、南沙区，止于南沙客运港站，大致呈南北走向。

广州地铁4号线全长60.03千米，共设24座车站（其中有1座为预留），其中14座地下站，10座高架站，采用4节编组L型列车。

广州地铁5号线（Guangzhou Metro Line 5）是广东省广州市建成运营的第5条地铁线路，于2009年12月28日开通运营一期工程（滘口站至文冲站），于2023年12月28日开通初期运营东延段工程（文冲站至黄埔新港站），其标志色为红色。

广州地铁5号线起于滘口站，途经荔湾区、越秀区、天河区和黄埔区，贯穿旧城中心区、环市路、珠江新城CBD、黄埔大道东、黄埔城区、黄埔东路和开发大道，止于黄埔新港站，大致呈东西走向。

广州地铁5号线线路全长41.66千米，地下段约39.7千米，高架段约2千米；共设置30座车站，除滘口站和坦尾站为高架车站外，其余全部为地下车站；列车采用6节编组L型列车。

广州地铁8号线（Guangzhou Metro Line 8）是中国广东省广州市第6条建成运营的地铁线路，于2010年9月25日经拆分开通运营首期工程（昌岗站至万胜围站），2010年11月3日开通运营西延段工程（凤凰新村站至昌岗站），2019年12月28日开通延长段工程（凤凰新村站至文化公园站），2020年11月26日开通北延段工程（文化公园站至滘心站），其标志色为蓝绿色。

广州地铁8号线起于滘心站，途经白云区、荔湾区、海珠区，贯穿广州国际会议展览中心、新港路沿线，止于万胜围站，大致呈“L字形”东西走向。

广州地铁8号线线路全长32.9千米，全部为地下线；共设置28座车站；列车采用6节编组A型列车。

广佛地铁（Guangfo Metro），又称“广佛线”或“佛山地铁1号线”，是中国广东省广州市（第7条）和佛山市境内的地铁线路，也是中国大陆首条跨越地级行政区的地铁线路，于2010年11月3日开通运营一期首通段（魁奇路站至西塱站），2015年12月28日开通运营一期后通段（西塱站至燕岗站），2016年12月28日开通运营二期（魁奇路站至新城东站），2018年12月28日开通运营二期后通段（燕岗站至沥滘站），标志色为黄绿色。

广佛地铁起于沥滘站，途经广州市的海珠区、荔湾区和佛山市的禅城区、南海区、顺德区，贯穿广东金融高新技术服务区、广佛都市圈，止于新城东站，大致呈“厂”字形走向。

广佛地铁线路全长37.96千米，全为地下线，其中佛山市内21.47千米，广州市内17.03千米；共设置25座车站，全为地下站，其中佛山市设15座，广州市设10座；使用4节编组B型列车。

广州地铁APM线（Zhujiang New Town Automated People Mover System），全称广州市珠江新城核心区市政交通项目旅客自动输送系统，于2010年11月8日开通运营，是广州地铁首条建成运营的自动导向轨道系统线路，其标志色为天蓝色。

广州地铁APM线起于广州塔站，途经天河区和海珠区；地处广州城中轴线，穿过珠江，贯穿珠江新城核心区域，连通广州塔、海心沙公园、天河体育中心等多个地标式建筑，止于林和西站，其大致呈南北走向。

广州地铁APM线全长3.94千米，全部为地下线；共设置9座车站，全部为地下车站；采用胶轮2节编组列车。

广州地铁6号线（Guangzhou Metro Line 6）是广州地铁建成投入使用的第9条地铁线路，于2013年12月28日开通运营一期工程（浔峰岗站至长湴站），2016年12月28日开通运营二期工程（长湴站至香雪站），其标志色为紫红色。

广州地铁6号线线路起于浔峰岗站，途经白云区、荔湾区、越秀区、天河区、黄埔区，贯穿坦尾、珠江北岸，止于香雪站，大致呈东西“U型”走向。

广州地铁6号线线路全长41.94千米，其中高架线路总长约2.7千米；共设置32座车站，其中浔峰岗站、横沙站、沙贝站为高架车站，其余全部为地下站；列车采用4节编组L型列车。

广州地铁7号线（Guangzhou Metro Line 7）是广州地铁第十条建成运营的地铁线路，于2016年12月28日开通运营一期工程（广州南站至大学城南站），于2022年5月1日开通运营一期西延顺德段（美的大道站至广州南站），于2023年12月28日开通运营二期（大学城南站-燕山站），标志色为嫩绿色。

广州地铁7号线起于美的大道站，途经佛山市顺德区、广州市番禺区和黄埔区，途经顺德北滘、广州南站、广州大学城、长洲岛、黄埔临港经济区、科学城和萝岗，东止于燕山站，大致呈西南-东北走向。

广州地铁7号线全长52.71千米，全部为地下线；共设置28座车站（1座暂缓开通），全部为地下车站；列车采用6节编组B型列车。

2017年12月28日，广州地铁9号线、地铁13号线，双线同期开通运营（广州第11-12条地铁线路）。

广州地铁9号线（Guangzhou Metro Line 9）是广州地铁建成运营的线路之一，于2017年12月28日试运营，标志色为薄荷绿，是花都区内的首条地铁线路，是广州北拓高效发展的重要交通骨干线；是中国在岩溶区域建造的首条地铁线，还是中国国内首条穿越高铁路基的地铁线路。

广州地铁9号线，线路起于高增站，途经白云区和花都区，贯穿花都汽车产业基地、广州北站片区、广州空港经济区，止于飞鹅岭站，大致呈“几”字形走向。

广州地铁9号线线路全长20.1千米，全部为地下线；共设置11座车站，全部为地下车站；列车采用6节编组B型列车，运行最高速度可达到120千米/小时。

广州地铁13号线（Guangzhou Metro Line 13）是广州地铁建成运营的线路，其标志色为橄榄绿，于2017年12月28日开通运营一期工程（鱼珠站至新沙站），于2025年9月开通首期延伸段（天河公园站至鱼珠站）。

截至2020年11月，广州地铁13号线起于鱼珠站，途经增城区和黄埔区，止于新沙站，大致呈东西走向。

截至2020年11月，广州地铁13号线线路全长27.03千米，全部为地下线；共设置11座车站，全部为地下车站；采用8节编组A型列车，是广州地铁首条使用8A编组列车的线路。

2018年12月28日，广州地铁14号线、地铁21号线，双线同期开通运营（广州第13、14条地铁线路）。

广州地铁14号线（Guangzhou Metro Line 14）是广州地铁建成运营的线路之一，于2017年12月28日开通运营知识城支线（新和站至镇龙站），于2018年12月28日开通运营一期工程（嘉禾望岗站至东风站），于2025年9月开通运营二期工程（乐嘉路站至嘉禾望岗站），其标志色为棕色。

广州地铁14号线主线起于嘉禾望岗站，途经白云区和从化区，止于东风站；知识城线起于新和站，途经白云区和黄埔区，止于镇龙站，大致呈“倒Y字”走向。

广州地铁14号线全长76.3千米，其中地下线44.3千米、高架线32千米；共设置22座车站，其中地下站15座、高架站7座；采用6节编组B型列车；主线采用快慢车结合运营模式。

广州地铁14号线设有嘉禾望岗至东风（设有快慢车），镇龙至新和两种交路；其中嘉禾望岗至东风的快车仅停靠嘉禾望岗站、白云东平站、新和站、从化客运站和东风站五座车站。

广州地铁21号线（Guangzhou Metro Line 21），是广州地铁建成运营的第14条线路，标志色为深蓝色，于2018年12月28日开通运营首通段工程（镇龙西站至增城广场站），于2019年12月20日开通后通段工程（员村站至镇龙西站），于2024年10月2日将终点站缩短至天河公园站。

广州地铁21号线，线路起于天河公园站，自西向东贯穿天河区、黄埔区和增城区，贯穿东部新城区域，止于增城广场站，大致呈“厂”字形走向。

广州地铁21号线线路全长60.4千米，其中地上段14.7千米，穿山隧道6.8千米，地下段38.9千米；共设置20座车站，其中地下站16座、高架站4座；采用6节编组B型列车。

广州地铁18号线（Guangzhou Metro Line 18）是中国广东省广州市境内第15条开通运营的城市轨道交通线路，是中国国内第一条时速160千米的全地下市域快线，于2021年9月28日开通运营首通段（万顷沙站至冼村站），标志色为湾区蓝。

广州地铁18号线线路起于冼村站，途经天河区、海珠区、番禺区、南沙区，串联珠江新城、琶洲片区、番禺广场及南沙万顷沙（明珠湾区）等板块；快速连接南沙新区及广州东站，止于万顷沙站，线路大致呈南北走向。

广州地铁18号线一期全长61.3千米，其中首通段全长58.3千米，全部为地下线，共设置9座车站（1站暂缓开通），全部为地下车站。设1个停车场，1个车辆段，列车采用8节编组市域D型列车。

广州地铁22号线（Guangzhou Metro Line 22），是中国广东省广州市境内第16条开通运营的城市轨道交通线路，是广州地铁市域快线之一，于2022年3月31日开通运营首通段（番禺广场站至陈头岗站），标志色为活力橙。

广州地铁22号线首通段线路起于番禺区番禺广场站，经祈福新村、广州南站商务区，贯穿番禺区，止于番禺区陈头岗站，后通段线路（陈头岗站-芳村站）、北延段线路大致呈南北走向，正在建设中。

广州地铁22号线首通段全长18.2千米，采用全地下敷设方式；共设地下车站4座；列车运行最高时速为160千米/小时，采用8节编组市域D型列车。

广州地铁11号线（Guangzhou Metro Line 11），是中国广东省广州市境内第17条建成运营的城市轨道交通线路，于2024年12月28日开通运营，其标志色为穗金色。

广州地铁11号线为环线，线路途经广州市天河区、白云区、越秀区、荔湾区和海珠区五个中心区，串起琶洲、金融城、天河北、白鹅潭、中大国际创新生态谷等重点发展板块。该线路的开通使得广州成为全国第8座暨粤港澳大湾区首座开通环线地铁的城市。

广州地铁11号线全长约44.2千米，全部为地下线；共设置31座车站（其中广州火车站、广州东站2座车站暂缓开通），全部为地下站；列车采用8节编组A型列车。

2025年6月29日，广州地铁10号线、地铁12号线，双线同期开通（广州第18、19条地铁线路）。
