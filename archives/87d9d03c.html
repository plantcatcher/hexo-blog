在地球漫长的演化史中，板块运动藏着无数地质奥秘。而GPlates，正是一款专为地球科学家、教育工作者与学生打造的开源跨平台桌面软件。

它能交互式可视化、操作板块构造及各类地质数据，轻松破解地球板块运动重建的复杂难题，成为探索地球动态演化过程的强力工具。

自发布以来，GPlates 凭借专业、易用的特性，早已成为全球地学界板块重建、古地理制图、地球动力学研究的核心利器，助力科研与教学解锁地球的前世今生。

作为一名GIS专业的地理自媒体，不写GPlates的教程简直说不过去。因此就有了这篇文章。

01 软件介绍

GPlates 是一款板块构造学专业程序。可在地质时间尺度上处理地质与古地理特征的重建工作，能交互式可视化矢量、栅格和体数据。PyGPlates 是 GPlates 的 Python 函数库，可让你在 Python 脚本中精细化调用 GPlates 的各项功能。

术语补充说明（适配地质领域使用）：

  1. plate-tectonics：板块构造学（地质学科核心术语，而非简单直译 “板块构造”）
  2. reconstructions：重建（地质领域特指 “地质 / 古地理特征的复原重建”）
  3. vector, raster and volume data：矢量、栅格和体数据（GPlates 核心数据类型，体数据对应三维地质数据）
  4. fine-grained access：精细化调用（而非字面 “细粒度访问”，贴合编程 + 地质场景的表达）

GPlates的功能包括：

  1. 处理和可视化多种几何体和格式的数据，包括栅格数据
  2. 将板块运动学与地球动力学模型连接起来
  3. 作为网格计算网络中的交互客户端
  4. 以便制作高质量的古地理地图

而我对这个软件感兴趣，则单纯是因为它能自主的模拟板块运动。
